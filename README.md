# Izagit Hub

Repositório para organizar projetos de sites institucionais.

## Primeiro projeto

A pasta `site-institucional` está reservada para receber os arquivos do primeiro site.

## GitHub Desktop

Clone este repositório pelo GitHub Desktop. Depois de editar os arquivos, faça um commit e use **Push origin** para enviar as alterações ao GitHub. Use **Fetch origin** e **Pull origin** para receber alterações remotas.

O projeto poderá ser desenvolvido com ferramentas como Lovable e publicado em uma hospedagem como a Hostinger, conforme os requisitos de cada site.
